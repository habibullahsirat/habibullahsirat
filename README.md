### MediFlow — Clinic Management SaaS

A full-stack clinic management platform designed to streamline healthcare operations.

- Clinic-based architecture and role-based access control.
- Patient and appointment management.
- Clinical records and prescription management.
- Billing, invoicing, and payment workflows.
- Built with Next.js, TypeScript, Prisma ORM, PostgreSQL, and Supabase.

**Status:** Active development.

### FinTrack — Personal Finance Management

A personal finance application designed to help users organize and monitor their financial activities.

- Financial transaction management.
- Structured database architecture.
- Full-stack application development.
- Built with Next.js, TypeScript, Prisma ORM, and PostgreSQL.

### Social Blog — Social Networking & Blogging

A full-stack social blogging application featuring user profiles and connection-based content visibility.

- User profiles and social connections.
- Public, friends-only, and private blog posts.
- Authentication and access control.
- Built with Next.js, Prisma ORM, PostgreSQL, and Supabase.
